# 一、世界观

## 1. 核心冲突

**状态：已锁定**

天庭统治三界，却把凡人视为维持秩序的成本。天庭垄断民间香火与愿力，强迫土地、灶神、门神等小神上缴百姓祈愿形成的力量。小神不得把愿力用回百姓身上，否则会被削名、贬职或清除。

凡人的祈愿得不到回应，天庭和上层神将却依靠香火维持权力。十二生肖不是天庭敕封的神将，而是代表农户、百姓和普通劳动者的民间抵抗者。

阎王名义上归天庭管辖。他掌握冥府和生死记录，却不满自己只能管理亡魂，暗中试图削弱天庭并取代玉皇。

## 2. 十二生肖登天战

**状态：已锁定**

- 十二生肖从不同方向共同进攻天庭。
- 鼠光与兔昭负责袭击一座边关哨站。
- 十二生肖最终全部阵亡。
- 不同生肖的死亡经过通过主线、旧我、小神仙事件、记忆残页和轮回试炼逐步揭晓。
- 序章只表现鼠光与兔昭所在战线。

## 3. 还魂与活体寄身

**状态：已锁定**

鼠光与兔昭的边关位于人间与冥府交界。鼠光战死后，尸体被死亡法则拖入黄泉，阎王因此得到原身体。

阎王向鼠光提出“一次性还魂契”，声称这是唯一一次还魂机会：

- 第一次回归使用鼠光自己的身体。
- 阎王选择鼠光，是因为他重情、痛苦、目标坚定，比其他人更容易操纵。
- 兔昭保护小神后灵魂出现异常，阎王无法稳定控制她，因此没有把她一起送回。
- 鼠光原身体无法继续承载第二次回归。
- 后续每轮使用一名仍活着的“承愿者”。

## 4. 承愿者与活借

**状态：已锁定**

### 公开说法

- 称呼：承愿者。
- 招募话术：让英雄借你的身体继续反抗天庭。
- 承诺：承愿者的灵魂会沉睡，英雄成功后他们能够醒来。

### 阎王内部说法

- 内部黑话：活借。
- 阎王在记录中把承愿者当作“身器”，而不是合作者。
- 系统说明统一使用：寄身者。

### 真相

- 承愿者仍然活着。
- 意识全程清醒，能感受疼痛、伤势和死亡，却无法控制身体。
- 无论鼠光通关还是死亡，承愿者身体最终都会衰亡。
- 鼠光被告知使用的是已经死亡的自愿身体，不知道活人被压在体内。
- 鼠光直到阎王背叛后才得知真相。
- 每一位承愿者拥有姓名、家乡和一句个人愿望，记录在“承愿名录”。
- 完整承愿名录在阎王背叛后一次性揭示。
- 首位承愿者和最终寄身者有重点剧情，其余保持短小但具体。
- 最终寄身者是前期出现过的凡人少年春生，曾见证十二生肖反抗并主动承愿。

## 5. 轮回资质

**状态：已锁定**

鼠光的灵魂可以在更换身体后保留完整记忆与自我，其他灵魂转移一次后便会崩散。这是他能够持续轮回的原因，但不提供直接战斗数值优势。

阎王真正需要的是多次轮回产生的动态行为数据：

- 其他生肖只留下一次死亡记录，数据固定。
- 鼠光不断重试，能够暴露并细化战斗习惯。
- 这些数据被用于制造越来越像他的旧我，并在最终战形成针对方案。

## 6. 天庭与冥府

### 天庭

- 最高统治者：玉皇。
- 玉皇通过天庭巡天记录发现“已死亡灵魂再次出现”，知道鼠光在违规轮回。
- 玉皇故意不阻止鼠光，把他当作诱饵，等待阎王暴露更多隐瞒。
- 玉皇准备在证据足够后同时清算鼠光和阎王。
- 玉皇只把鼠光视为低等反抗者和政治诱饵，不认为他值得亲自处理。
- 普通天兵大多是主动支持天庭秩序的人，不是统一的无辜受害者。
- 少数天兵会逐渐清醒，意识到制度问题。
- 低阶身份不等于无辜，玩家需要通过行为和对话判断立场。
- 多数普通敌人死战，少数清醒者在条件满足后投降。
- 玩家可放过投降者，放过可能影响后续事件。

### 冥府

- 阎王名义上服从天庭，实际谋求取代玉皇。
- 阎王知道玉皇在利用鼠光，反过来借鼠光把玉皇引入单挑环境。
- 阎王知道只有暂时隔开玉皇与天庭护卫，才有机会夺取其力量。
- 玉皇与阎王的终局对抗是双方互相算计，不只是一方突然背叛。
- 阎王掌握生死簿、轮回记录和灵魂调配。
- 玄简是掌籍郎，负责抄录姓名、合同和战斗记录。
- 阎王扣押玄简自己的生死簿页，迫使他服从。

## 7. 香火与愿力

**状态：已锁定**

### 香火是愿力的记账形式

- 百姓的祈愿本身产生愿力。愿力是具体的一件件事：求雨、求丰收、求平安、求病愈。
- 百姓在祭祀场所行祭祀，愿力被记录为**香火**。
- 香火不是香本身，而是愿力被登记、可结算之后的形式。
- 香火因此有两个身份：对神，它是维持存在与力量的来源；对天庭，它是可计价、可储存、可流通的货币。
- 天庭最根本的罪，是把「神回应人」的关系改成了可交易的账目。

原始关系：

```
百姓祈愿 → 神回应 → 百姓再祭 → 关系持续
```

天庭改制后：

```
百姓祈愿 → 记录为香火 → 上缴 → 兑换权柄
```

- 小神被禁止把愿力用回百姓身上。一旦用回去，香火就不再是货币，而变回关系。
- 这条禁令是核心冲突的制度根源，不是治安条款。

### 香火是零和的

- 香火总量由人口、收成与祭祀点数量决定，不能凭空增加。
- 愿力不会自行增殖，也不会因储存而变多。
- 一次祭祀的愿力只流向受祭对象。

推论：

- 一个神多取，另一个神必然少取。
- 天庭必须不断扩张神系与祭祀点，因为总盘子固定。
- 神与神之间存在真实的资源竞争，「抢香火」不依赖性格恶毒。
- 神系内部的倾轧是数学问题，不是道德问题。

民间说法：

- 「香火不能断」——香火是续着的火，必须持续有人添。

### 神依赖香火维持存在

- 香火是神维持神格与力量上限的基础，不是施法的即时消耗。
- 施法不按次扣香火。香火充足时，神施法不感到负担。
- 香火长期不足时，神的整体力量下降，而不是单纯放不出招。
- 香火彻底断绝时神格消失，即民间所说的「断了香火」。
- 神的层级越高，维持存在所需香火越多。

这条机制使天庭的征收具有物理后果：天庭征收的不只是财物，而是神的存续条件。

### 天庭的征收体系

- 征收由低级神仙负责。土地、灶神、门神等基层神直接面对百姓。
- 香火逐层向上汇总，每一层都会截留。
- 天庭内部香火可流通，用于交易、购买和累积升职。
- 天庭按配额考核下层神，未达标者会被削名、贬职或清除。
- 基层神因此处于最不利位置：直接干活、被禁止回应百姓，还要承担最重的上缴压力。
- 神职体系同时是行政体系与市场。

### 香火的用途

- 物品与资源。
- 神职晋升。
- 天庭体系内的流通与结算。

香火不涉及轮回。生死与轮回不通过香火运作，两者不在同一范畴。

### 冥府

- 冥府与天庭一样，同样征收香火、同样逐层上缴。
- 冥府的香火来源是祭祀：丧葬、上坟、中元节等与亡者相关的祭祀。
- 冥府是天庭体系内的下级机构，不是体系外的势力。
- 冥府缺少可自由扩张的祭祀点，收入上限固定，规模远小于天庭的日常供奉。
- 生死与轮回不通过香火运作，因此香火不进入生死簿的账目。

玄简：

- 生死簿的记录是香火体系不能计价的东西。
- 阎王扣押他的生死簿页，因此等于控制冥府唯一不进入香火结算的账本。

### 十二生肖与体系的关系

- 十二生肖不是天庭敕封的神将，不在香火体系内部。
- 他们既没有配额，也没有升职路径。
- 天庭无法用扣香火的方式管理他们。
- 这也意味着他们没有体系提供的资源，只能依靠自己。

### 玩家侧的香火

- 香火是本轮唯一货币，死亡后清空，不转为永久货币。
- 香火用于商店与部分事件，商店由香火巡检祝安经营。
- 玩家夺回的香火，原本是百姓被掠夺的部分。
- 玩家在祝安处花掉香火，等于把百姓的东西还回民间。

鼠光不依赖香火：

- 鼠光不靠香火维持力量，香火不会转化为他的神力。
- 他无法与天庭进行经济战，因此只能依靠精准格挡、距离判断与换武这些技术手段。
- 他夺回的香火只能花掉，不能变成自身强度。
- 由此「以弱抗强」与「夺回的香火还给民间」两个主题同时成立。
- 若鼠光也能靠香火强化，敌我力量对比会被拉平，两个主题都会被削弱。

### 与双资源的接口

**状态：暂定**

- 双资源中的**气**是缓慢恢复的生存资源，可以解释为「愿力稀缺」在玩家身上的体现。
- 本条为可选表现层解释，不影响战斗数值。
- 玩家从击败神将处夺回香火，是世界观与奖励系统之间的接口。

# 二、主要角色

## 1. 鼠光

**身份：主角 / 鼠 / 已阵亡的民间抵抗者**

**状态：已锁定**

- 性格冷峻、寡言、目标至上，不依赖热血演讲表达理想。
- 长期目睹天庭漠视凡人，因此不相信权力和口头承诺。
- 外表冷漠，但会主动保护具体的人。
- 兔昭是唯一真正接近他的朋友。
- 兔昭死后，他变得更加封闭。
- 他认为继续登天既是在保护百姓，也是在替兔昭完成愿望。
- 他会为百姓长期目标压下私人疑问，因此多次放过阎王的破绽。

视觉：

- 瘦长鼠形兽人。
- 长尾、破损围巾。
- 单把短刃。
- 核心轮廓突出孤独、克制和高速。

初始武器：

- 残锋短刃。
- 短兵原型。
- 速度快、攻击范围短，要求贴近战斗。

## 2. 兔昭

**身份：兔 / 鼠光的挚友**

**状态：已锁定**

- 乐观、主动，相信反抗会带来更好的未来。
- 长期主动接近鼠光，最终成为他唯一信任的朋友。
- 和鼠光一样希望百姓不再受苦，但更愿意相信明天。
- 两人进攻边关。鼠光先战死，兔昭继续任务，随后保护一名小神并战死。
- 兔昭死亡后灵魂异常，阎王无法稳定控制她。
- 第一轮正式轮回结束并首次返回冥府后，触发兔昭短章。
- 短章从兔昭视角补全同一场战斗的后半段。
- 兔昭不负责提前揭露借身、记录或旧我机制。

视觉：

- 月白毛发。
- 琥珀色眼睛。
- 红色腕绳。
- 双短刃。
- 与鼠光的暗色轮廓形成明确对照。

## 3. 玄简

**身份：掌籍郎 / 记录小神**

**状态：已锁定**

- 负责记录姓名、契约、死亡与战斗数据。
- 被阎王扣押自己的生死簿页，随时可能被彻底抹除。
- 相信承愿者灵魂沉睡的官方说法，不知道他们一直清醒。
- 暗中保存十二生肖真名、残页和与兔昭有关的记录。
- 阎王背叛后，玄简牺牲自己的生死簿页，把鼠光从契约中拉出。
- 正常路线：留下残缺警告后消失。
- 隐藏路线：保住姓名，但失去冥府神职。

## 4. 阎王

**身份：冥府最高管理者 / 表面盟友 / 主要反派**

**状态：已锁定**

- 表面是唯一愿意帮助十二生肖的神。
- 实际利用十二生肖削弱天庭、收集战斗数据。
- 使用一次性还魂契取得鼠光信任。
- 后续回归使用活体寄身，隐瞒承愿者仍然清醒。
- 记录鼠光的战斗习惯并制造旧我。
- 知道玉皇在监视并利用鼠光，故意继续推动轮回，引诱玉皇亲自下场。
- 计划借鼠光隔开玉皇与天庭护卫，再夺取玉皇力量。
- 玩家击败玉皇、杀死玉皇时，阎王顺着还魂契吸收其神魂和权柄。
- 最终形态：阎王·夺天相。
- 不设置隐藏真名，始终称为阎王。

## 5. 玉皇

**身份：天庭最高统治者**

**状态：已锁定**

- 代表天庭最高权柄与压迫秩序。
- 说话冷静、威严，始终用“秩序”和“大局”为压迫辩护。
- 通过巡天记录知道鼠光不断违规回归。
- 故意放任鼠光，目的是迫使阎王暴露更多秘密。
- 认为可以同时清算鼠光和阎王，因此低估了两人。
- 正常路线中被鼠光杀死。
- 死后被阎王顺契约吸收。
- 隐藏路线中被击败、剥夺权柄并封印，但没有被杀死。

## 6. 许安

**身份：首位承愿者 / 凡人青年**

**状态：已锁定**

- 来自边关附近的村庄。
- 曾亲眼见到鼠光和兔昭保护百姓。
- 自愿承愿，认为英雄借身能够帮助反抗天庭。
- 被阎王欺骗，不知道自己的意识会一直清醒。
- 无论鼠光通关还是死亡，许安的身体最终都会衰亡。
- 第一次保底旧我使用许安的身体。
- 玩家击败或绕过许安形成的旧我时会看到他的真实面孔，但当时不知道他的名字。
- 阎王背叛并揭开承愿名录后，玩家才知道许安的身份。

## 7. 春生

**身份：最终寄身者 / 凡人少年**

**状态：已锁定**

- 两个字姓名，全名为春生。
- 前期出现过，亲眼见过十二生肖反抗。
- 主动承愿，并相信英雄能够结束天庭的压迫。
- 在隐藏路线中成为最终寄身者。
- 隐藏结局中身体仍然死亡，但断轮印保住其灵魂，使其能够正常轮回。

# 四、单局结构

## 1. 总览

**状态：已锁定**

- 每轮固定经过 20 个节点。
- 每个区域固定安排 5 个节点。
- 单轮目标时长 60–120 分钟。
- 正常主线目标为 3–5 轮。
- 每次轮回从无雨乡开始。
- 已解锁区域不会让玩家跳过低层路线。

## 2. 四大区域

### 无雨乡

- 固定起点。
- 主题：天庭镇压、破坏与庇护百姓。
- 环境：残破村庙、山道、临时庇护所、倒塌建筑、干旱田地与香火断点。
- 固定精英：断雨校尉。
- 精英机制：封锁云雨、逼缴香火；战斗会制造干旱区域并关闭部分场地的水气。
- 区域 Boss：夺愿神。
- Boss 机制：吸收玩家的势并转化为护盾；玩家击破香炉或愿牌夺回资源。

### 罡风隘

- 可与天河录库交换顺序。
- 主题：风、垂直空间、登天封锁。
- 环境：断桥、浮台、强风、关隘机关。
- 掉落路线失败不会即死，只损失气并回到平台。
- 固定精英：风眼侍者。
- 精英机制：周期制造强风与气流区，迫使玩家切换高低路线和武器距离。
- 区域 Boss：锁门天将。
- Boss 机制：关门切割竞技场，封锁高低路线；玩家通过换武和破门恢复空间。

### 天河录库

- 可与罡风隘交换顺序。
- 主题：记录、复制、姓名和档案。
- 环境：旋转书架、封条、卷宗和投影机关。
- 固定精英：焚卷吏。
- 精英机制：焚烧卷宗制造墨烟区域，并试图烧毁玩家的招式信息，但不会永久删除已解锁内容。
- 区域 Boss：削名判官。
- Boss 机制：
  - 第一阶段“录名”：记录常用武器与武功。
  - 第二阶段“削名”：封锁一个武器槽或主动招式，玩家击破封条恢复。
  - 第三阶段“判词成真”：同时最多两条判词，第三条替换最早一条。
- 判词类型示例：禁止跳跃、封锁武器、周期落判。
- 每条判词必须有明确文字、场地标记和至少一种破除方式。

### 玉京天阙

- 固定终点。
- 主题：权柄、领域和最终秩序。
- 环境：神印、法令区域、可切换的场地规则。
- 固定精英：封敕使。
- 精英机制：宣读封敕，逐条限制场地与招式；玩家需在限制完全生效前击破敕令。
- 正常路线 Boss：玉皇。
- 正常玉皇分两个阶段：
  1. 法旨划分场地并召唤神将虚影。
  2. 玉皇亲自下场，用近距离权柄和瞬移压迫玩家。
- 隐藏路线玉皇分三个阶段，主动移动，并与断轮印产生破坏权柄的交互。

## 3. 路线变化

**状态：已锁定**

- 无雨乡固定为起点。
- 罡风隘与天河录库可以交换顺序。
- 玉京天阙固定为终点。
- 区域内部从“普通战、精英、小神仙事件、商店、休整、失名旧我”中生成。
- 不固定套用同一序列。
- 每个区域固定包含 5 个节点，节点类型与顺序随机变化。
- 地图仍可提供多条连线路径，但单次区域推进必须完成 5 个节点。
- 每个区域有一个固定双阶段精英。
- 失名旧我属于额外可选精英，不占固定精英位。
- 第一次完整轮回结束后的下一轮，保证出现一次剧情旧我，玩家可以战斗或绕开。
- 这次保底旧我使用许安的身体；此后旧我重新进入概率池。

# 五、战斗系统

## 1. 核心定位

**状态：已锁定**

- 一屏横版 1v1 竞技场。
- 正常敌人使用单条生命。
- Boss 使用多阶段结构。
- 战斗深度为中等：
  - 轻击。
  - 重击。
  - 挑空。
  - 空中追击。
  - 防御。
  - 闪避。
  - 精准格挡。
  - 3 个主动武功。

核心能力层级：

1. 站位与距离决定局势。
2. 精准格挡决定攻防转换。
3. 武器切换负责解决具体距离、防御和敌人阶段问题。

### 手柄参考布局

**状态：暂定**

- 左摇杆：移动
- A：跳跃
- B：闪避
- X：轻击
- Y：重击
- LB：防御
- RB：切换武器
- LT：按住进入武功修饰
- LT + X/Y/B：释放三个主动武功

键盘映射留到原型阶段验证。

## 2. 双资源

**状态：已锁定**

### 气

- 用于防御、闪避、移动技能和特殊移动。
- 缓慢恢复。
- 鼓励玩家管理生存资源。

### 势

- 通过普攻命中、连段和精准格挡积攒。
- 用于释放主动武功。
- 受击会降低或打断势。
- 势不会在没有战斗行为时自然刷满。

## 3. 防御与格挡

**状态：已锁定**

- 长按防御。
- 消耗气的闪避。
- 精准格挡。
- 防御拥有独立架势值。
- 连续受击会破防，重击与部分武功更有效。

精准格挡成功：

- 恢复气。
- 积攒势。
- 使敌人短暂硬直。
- 不同武器可衔接自己的反击招式。

精准格挡失败：

- 自动转为普通防御。
- 额外消耗气。
- 增加架势值。

## 4. 五种武器格挡原型

**状态：已锁定**

| 原型 | 防御特征 |
| --- | --- |
| 短兵 | 窗口最短，反击收益最高 |
| 长兵 | 正面范围宽，收招较慢 |
| 重兵 | 可承受多段，精准格挡造成更大硬直或破霸体 |
| 软兵 | 窗口较宽，偏推开、转移方向和重整距离 |
| 远程特殊格挡 | 近战精准格挡较弱，可偏转 projectile 或反击突进 |

基础武器清单：

- 短兵：短剑、直剑、双匕。
- 长兵：长枪、棍、戟。
- 重兵：斧、锤、盾刃。
- 软兵：鞭、链、流星锤。
- 远程：弓、弩、暗器。

数量规则：

- 武器不设固定总量。
- 新增武器必须填充明确玩法缺口。
- 新增武器必须拥有独立距离、节奏或格挡差异。

## 5. 双武器

**状态：已锁定**

- 玩家携带 2 把武器。
- 每把武器拥有独立连段计数。
- 切换后可使用一次专用换武攻击。
- 原武器连段中断。
- 切换存在冷却。
- 受击硬直中不能切换。
- 普通战斗平均切换 1–3 次。

## 6. 武功秘籍

**状态：已锁定**

- 秘籍完全独立，不设公开的刚柔快破险门派。
- 每本秘籍围绕一个主要触发条件。
- 每本秘籍提供一个主要效果。
- 后台可用隐藏标签平衡，不在界面显示为门派。
- 新增秘籍不设总量，但必须填补构筑缺口。
- 主动招式最多 3 个。
- 被动秘籍效果最多 4 个。
- 主动招式通过“武功修饰键 + 攻击键”释放。
- 主动招式消耗势。

## 7. 武器切换规则

**状态：已锁定**

## 4. 战斗实现基线

### 资源

- 生命：归零后重试当前节点。
- 架势：防御普通攻击时承受，归零进入破防。
- 气：用于防御、闪避和潜地；精准格挡返还气。
- 势：所有玩家攻击均消耗势；攻击命中、精准格挡和格挡反击继续积累势。非攻击状态下每秒缓慢恢复 `2` 点。

### 基础操作

- 轻击、重击、跳跃、空中攻击。
- 按住防御、闪避、精准格挡。
- 两把武器切换与换武攻击。
- 主动武功：破势斩。
- 鼠光特殊技能：自由潜地与破土上挑。

### 攻击与受击

- 普通攻击可被防御或精准格挡。
- 红色不可格挡攻击必须通过闪避、潜地或脱离范围处理。
- 受击状态分为僵直、击飞和倒地。
- 平推类攻击造成僵直；击飞类攻击进入击飞态；砸地击和击飞落地进入倒地态。
- 倒地期间可用重击触发地面追击。
- 浮空追加预算为普通敌人 3 次、精英 2 次、Boss 1 次；重型敌人可以不可击飞。

### 空中攻击

- 空中轻击沿用地面轻击的招式逻辑和连段语言。
- 空中重击为砸地击，前摇和后摇较大，伤害较高。
- 砸地击命中后使目标倒地；被格挡时消耗大量格挡气。

### 防御

- 防御、闪避和潜地消耗气，具体数值待调。
- 精准格挡成功恢复气与势，并制造敌人硬直。
- 敌人近距离时自动释放武器专属反击：短刃三段快斩，长枪突刺后退。
- 气达到阈值后，可以在受击状态手动触发一次绝境精准格挡；成功或失败都清空气，倒地时不可使用。

### 连招

- 不做固定三段连招，采用两段共用起手，第二段后按方向与轻重击分支。
- 短刃包含快速三连、突进斩、上挑、重击终结和换武追击。
- 长枪包含连续突刺、平推、挑枪击飞、重击终结和换武追击。
- 命中和挥空都能继续固定连段，但命中后的输入缓冲窗口更宽。
- 当前势消耗：普通轻击 `8`、中立终结技 `12`、前突/上挑/换武 `15`、重击/砸地/地面追击 `20`、破土攻击 `15`。

### 自由潜地

- 主地面可自由潜地，浮空平台和空中不可使用。
- 地下持续消耗气，地面通过延迟墨色裂纹暴露近似位置。

- 钻出后没有惩罚性硬直；按攻击键可直接衔接破土上挑。

### 旧我

- 只读取上一战数据，不读取当前按键。
