一、世界观

1. 核心冲突

状态：已锁定

天庭统治三界，却把凡人视为维持秩序的成本。天庭垄断民间香火与愿力，强迫土地、灶神、门神等小神上缴百姓祈愿形成的力量。小神不得把愿力用回百姓身上，否则会被削名、贬职或清除。

凡人的祈愿得不到回应，天庭和上层神将却依靠香火维持权力。十二生肖不是天庭敕封的神将，而是代表农户、百姓和普通劳动者的民间抵抗者。

阎王名义上归天庭管辖。他掌握冥府和生死记录，却不满自己只能管理亡魂，暗中试图削弱天庭并取代玉皇。

2. 十二生肖登天战

状态：已锁定

  • 十二生肖从不同方向共同进攻天庭。
  • 鼠光与兔昭负责袭击一座边关哨站。
  • 十二生肖最终全部阵亡。
  • 不同生肖的死亡经过通过主线、旧我、小神仙事件、记忆残页和轮回试炼逐步揭晓。
  • 序章只表现鼠光与兔昭所在战线。

3. 还魂与活体寄身

状态：已锁定

鼠光与兔昭的边关位于人间与冥府交界。鼠光战死后，尸体被死亡法则拖入黄泉，阎王因此得到原身体。

阎王向鼠光提出“一次性还魂契”，声称这是唯一一次还魂机会：

  • 第一次回归使用鼠光自己的身体。
  • 阎王选择鼠光，是因为他重情、痛苦、目标坚定，比其他人更容易操纵。
  • 兔昭保护小神后灵魂出现异常，阎王无法稳定控制她，因此没有把她一起送回。
  • 鼠光原身体无法继续承载第二次回归。
  • 后续每轮使用一名仍活着的“承愿者”。

4. 承愿者与活借

状态：已锁定

公开说法

  • 称呼：承愿者。
  • 招募话术：让英雄借你的身体继续反抗天庭。
  • 承诺：承愿者的灵魂会沉睡，英雄成功后他们能够醒来。

阎王内部说法

  • 内部黑话：活借。
  • 阎王在记录中把承愿者当作“身器”，而不是合作者。
  • 系统说明统一使用：寄身者。

真相

  • 承愿者仍然活着。
  • 意识全程清醒，能感受疼痛、伤势和死亡，却无法控制身体。
  • 无论鼠光通关还是死亡，承愿者身体最终都会衰亡。
  • 鼠光被告知使用的是已经死亡的自愿身体，不知道活人被压在体内。
  • 鼠光直到阎王背叛后才得知真相。
  • 每一位承愿者拥有姓名、家乡和一句个人愿望，记录在“承愿名录”。
  • 完整承愿名录在阎王背叛后一次性揭示。
  • 首位承愿者和最终寄身者有重点剧情，其余保持短小但具体。
  • 最终寄身者是前期出现过的凡人少年春生，曾见证十二生肖反抗并主动承愿。

5. 轮回资质

状态：已锁定

鼠光的灵魂可以在更换身体后保留完整记忆与自我，其他灵魂转移一次后便会崩散。这是他能够持续轮回的原因，但不提供直接战斗数值优势。

阎王真正需要的是多次轮回产生的动态行为数据：

  • 其他生肖只留下一次死亡记录，数据固定。
  • 鼠光不断重试，能够暴露并细化战斗习惯。
  • 这些数据被用于制造越来越像他的旧我，并在最终战形成针对方案。

6. 天庭与冥府

天庭

  • 最高统治者：玉皇。
  • 玉皇通过天庭巡天记录发现“已死亡灵魂再次出现”，知道鼠光在违规轮回。
  • 玉皇故意不阻止鼠光，把他当作诱饵，等待阎王暴露更多隐瞒。
  • 玉皇准备在证据足够后同时清算鼠光和阎王。
  • 玉皇只把鼠光视为低等反抗者和政治诱饵，不认为他值得亲自处理。
  • 普通天兵大多是主动支持天庭秩序的人，不是统一的无辜受害者。
  • 少数天兵会逐渐清醒，意识到制度问题。
  • 低阶身份不等于无辜，玩家需要通过行为和对话判断立场。
  • 多数普通敌人死战，少数清醒者在条件满足后投降。
  • 玩家可放过投降者，放过可能影响后续事件。

冥府

  • 阎王名义上服从天庭，实际谋求取代玉皇。
  • 阎王知道玉皇在利用鼠光，反过来借鼠光把玉皇引入单挑环境。
  • 阎王知道只有暂时隔开玉皇与天庭护卫，才有机会夺取其力量。
  • 玉皇与阎王的终局对抗是双方互相算计，不只是一方突然背叛。
  • 阎王掌握生死簿、轮回记录和灵魂调配。
  • 玄简是掌籍郎，负责抄录姓名、合同和战斗记录。
  • 阎王扣押玄简自己的生死簿页，迫使他服从。

二、主要角色

1. 鼠光

身份：主角 / 鼠 / 已阵亡的民间抵抗者

状态：已锁定

  • 性格冷峻、寡言、目标至上，不依赖热血演讲表达理想。
  • 长期目睹天庭漠视凡人，因此不相信权力和口头承诺。
  • 外表冷漠，但会主动保护具体的人。
  • 兔昭是唯一真正接近他的朋友。
  • 兔昭死后，他变得更加封闭。
  • 他认为继续登天既是在保护百姓，也是在替兔昭完成愿望。
  • 他会为百姓长期目标压下私人疑问，因此多次放过阎王的破绽。

视觉：

  • 瘦长鼠形兽人。
  • 长尾、破损围巾。
  • 单把短刃。
  • 核心轮廓突出孤独、克制和高速。

初始武器：

  • 残锋短刃。
  • 短兵原型。
  • 速度快、攻击范围短，要求贴近战斗。

2. 兔昭

身份：兔 / 鼠光的挚友

状态：已锁定

  • 乐观、主动，相信反抗会带来更好的未来。
  • 长期主动接近鼠光，最终成为他唯一信任的朋友。
  • 和鼠光一样希望百姓不再受苦，但更愿意相信明天。
  • 两人进攻边关。鼠光先战死，兔昭继续任务，随后保护一名小神并战死。
  • 兔昭死亡后灵魂异常，阎王无法稳定控制她。
  • 第一轮正式轮回结束并首次返回冥府后，触发兔昭短章。
  • 短章从兔昭视角补全同一场战斗的后半段。
  • 兔昭不负责提前揭露借身、记录或旧我机制。

视觉：

  • 月白毛发。
  • 琥珀色眼睛。
  • 红色腕绳。
  • 双短刃。
  • 与鼠光的暗色轮廓形成明确对照。

3. 玄简

身份：掌籍郎 / 记录小神

状态：已锁定

  • 负责记录姓名、契约、死亡与战斗数据。
  • 被阎王扣押自己的生死簿页，随时可能被彻底抹除。
  • 相信承愿者灵魂沉睡的官方说法，不知道他们一直清醒。
  • 暗中保存十二生肖真名、残页和与兔昭有关的记录。
  • 阎王背叛后，玄简牺牲自己的生死簿页，把鼠光从契约中拉出。
  • 正常路线：留下残缺警告后消失。
  • 隐藏路线：保住姓名，但失去冥府神职。

4. 阎王

身份：冥府最高管理者 / 表面盟友 / 主要反派

状态：已锁定

  • 表面是唯一愿意帮助十二生肖的神。
  • 实际利用十二生肖削弱天庭、收集战斗数据。
  • 使用一次性还魂契取得鼠光信任。
  • 后续回归使用活体寄身，隐瞒承愿者仍然清醒。
  • 记录鼠光的战斗习惯并制造旧我。
  • 知道玉皇在监视并利用鼠光，故意继续推动轮回，引诱玉皇亲自下场。
  • 计划借鼠光隔开玉皇与天庭护卫，再夺取玉皇力量。
  • 玩家击败玉皇、杀死玉皇时，阎王顺着还魂契吸收其神魂和权柄。
  • 最终形态：阎王·夺天相。
  • 不设置隐藏真名，始终称为阎王。

5. 玉皇

身份：天庭最高统治者

状态：已锁定

  • 代表天庭最高权柄与压迫秩序。
  • 说话冷静、威严，始终用“秩序”和“大局”为压迫辩护。
  • 通过巡天记录知道鼠光不断违规回归。
  • 故意放任鼠光，目的是迫使阎王暴露更多秘密。
  • 认为可以同时清算鼠光和阎王，因此低估了两人。
  • 正常路线中被鼠光杀死。
  • 死后被阎王顺契约吸收。
  • 隐藏路线中被击败、剥夺权柄并封印，但没有被杀死。

6. 许安

身份：首位承愿者 / 凡人青年

状态：已锁定

  • 来自边关附近的村庄。
  • 曾亲眼见到鼠光和兔昭保护百姓。
  • 自愿承愿，认为英雄借身能够帮助反抗天庭。
  • 被阎王欺骗，不知道自己的意识会一直清醒。
  • 无论鼠光通关还是死亡，许安的身体最终都会衰亡。
  • 第一次保底旧我使用许安的身体。
  • 玩家击败或绕过许安形成的旧我时会看到他的真实面孔，但当时不知道他的名字。
  • 阎王背叛并揭开承愿名录后，玩家才知道许安的身份。

7. 春生

身份：最终寄身者 / 凡人少年

状态：已锁定

  • 两个字姓名，全名为春生。
  • 前期出现过，亲眼见过十二生肖反抗。
  • 主动承愿，并相信英雄能够结束天庭的压迫。
  • 在隐藏路线中成为最终寄身者。
  • 隐藏结局中身体仍然死亡，但断轮印保住其灵魂，使其能够正常轮回。

三、叙事结构

1. 主线视角

状态：已锁定

  • 紧贴鼠光的第三人称视角。
  • 只在兔昭残页、生肖试炼和特殊记忆中切换视角。
  • 玩家可以通过线索比鼠光更早意识到异常。
  • 少量对话选择影响线索、小神仙关系和对白，不直接改变主结局。

2. 序章

状态：已锁定

序章承担操作教学，分三个可玩段落：

  1. 基础战斗教学。
  2. 哨站精英战。
  3. 鼠光战败、坠入黄泉并立下一次性还魂契。

具体经过：

  • 鼠光与兔昭共同攻击天庭哨站。
  • 击败精英后，天庭增援赶到。
  • 鼠光独自断后，让兔昭继续任务。
  • 鼠光战死，尸体因边界法则落入冥府。
  • 阎王取得尸体并提出还魂契。
  • 正式轮回从无雨乡底部开始，不能直接返回哨站。

3. 正常主线推进

状态：已锁定

  • 玩家目标是在约 3–5 轮内完成正常主线。
  • 每轮固定经过 20 个节点，目标时长约 60–120 分钟。
  • 主线与轮回线索分散在路线、事件、旧我和记忆中。
  • 除第一次剧情保底外，旧我并非每轮必然出现。
  • 旧我出现概率受死亡区域、路线和证词数量影响。
  • 主线对话提供少量选择，不直接决定隐藏结局。

认知推进

  1. 玩家以为阎王是唯一盟友。
  2. 第一次完整轮回结束后，保底旧我出现在路线中；玩家可以战斗或绕开，但会看到它复现鼠光的攻击距离、连招和闪避方向。
  3. 玩家看到旧我被击败或魂相解除后恢复成不同凡人的脸，但鼠光将其解释为术法残留。
  4. 玩家通过承愿者、兔昭残页、蛇牙记录和猴影档案逐步意识到阎王记录真相。
  5. 玩家与玉皇交战时才得知：玉皇一直故意放任鼠光，想借此逼阎王暴露。
  6. 玩家击败玉皇，阎王证明自己同样早有预谋，并吸收玉皇力量。
  7. 阎王揭示承愿者始终清醒，并故意把责任推给鼠光。

4. 兔昭短章

状态：已锁定

  • 触发：击败无雨乡区域 Boss，首次返回冥府后强制触发。
  • 玩家操控兔昭，从她的视角补全同一场战斗。
  • 主要表现兔昭保护小神并战死。
  • 不提前揭露借身、承愿者意识或旧我机制。

5. 轮回见闻

状态：已锁定

轮回见闻既是剧情档案，也是战斗图鉴。

线索来源：

  • 小神仙事件。
  • 旧我战斗。
  • 关卡探索。
  • 兔昭残页。
  • 玄简保存的生死簿页。
  • 对白和环境反馈。

规则：

  • 部分小神仙事件会写入轮回见闻。
  • 涉及姓名、承愿者、记录、借身或阎王的选择更容易产生关键线索。
  • 线索状态跨轮回保留。
  • 关键证词如果错过，会重新进入后续可获取池。
  • 普通隐秘遗物可以错过，不影响隐藏结局。
  • 击败敌人或解锁物品后，记录招式、判词、触发条件和基础对策。
  • 不提供训练模式或一键实战演示。

6. 八条关键证词

状态：已锁定

  • 总数：8 条。
  • 分布：四个区域各贡献两条。
  • 来源混合：
  • 2 条来自小神仙事件。
  • 2 条来自旧我或复制体。
  • 2 条来自关卡探索。
  • 2 条来自剧情节点。
  • 集齐后，“轮回见闻”自动拼成断轮契。
  • 关键证词不会永久错过。
  • 旧我不是集齐证词的必经条件，只提供额外出处与宿主故事。

7. 正常结局

状态：已锁定

  1. 玉皇在战前揭露自己一直放任鼠光，目的是逼阎王暴露。
  2. 鼠光击败并杀死玉皇。
  3. 阎王证明自己早有预料，顺着还魂契吸收玉皇神魂与权柄。

四、单局结构

1. 总览

状态：已锁定

  • 每轮固定经过 20 个节点。
  • 每个区域固定安排 5 个节点。
  • 单轮目标时长 60–120 分钟。
  • 正常主线目标为 3–5 轮。
  • 每次轮回从无雨乡开始。
  • 已解锁区域不会让玩家跳过低层路线。

2. 四大区域

无雨乡

  • 固定起点。
  • 主题：天庭镇压、破坏与庇护百姓。
  • 环境：残破村庙、山道、临时庇护所、倒塌建筑、干旱田地与香火断点。
  • 固定精英：断雨校尉。
  • 精英机制：封锁云雨、逼缴香火；战斗会制造干旱区域并关闭部分场地的水气。
  • 区域 Boss：夺愿神。
  • Boss 机制：吸收玩家的势并转化为护盾；玩家击破香炉或愿牌夺回资源。

罡风隘

  • 可与天河录库交换顺序。
  • 主题：风、垂直空间、登天封锁。
  • 环境：断桥、浮台、强风、关隘机关。
  • 掉落路线失败不会即死，只损失气并回到平台。
  • 固定精英：风眼侍者。
  • 精英机制：周期制造强风与气流区，迫使玩家切换高低路线和武器距离。
  • 区域 Boss：锁门天将。
  • Boss 机制：关门切割竞技场，封锁高低路线；玩家通过换武和破门恢复空间。

天河录库

  • 可与罡风隘交换顺序。
  • 主题：记录、复制、姓名和档案。
  • 环境：旋转书架、封条、卷宗和投影机关。
  • 固定精英：焚卷吏。
  • 精英机制：焚烧卷宗制造墨烟区域，并试图烧毁玩家的招式信息，但不会永久删除已解锁内容。
  • 区域 Boss：削名判官。
  • Boss 机制：
  • 第一阶段“录名”：记录常用武器与武功。
  • 第二阶段“削名”：封锁一个武器槽或主动招式，玩家击破封条恢复。
  • 第三阶段“判词成真”：同时最多两条判词，第三条替换最早一条。
  • 判词类型示例：禁止跳跃、封锁武器、周期落判。
  • 每条判词必须有明确文字、场地标记和至少一种破除方式。

玉京天阙

  • 固定终点。
  • 主题：权柄、领域和最终秩序。
  • 环境：神印、法令区域、可切换的场地规则。
  • 固定精英：封敕使。
  • 精英机制：宣读封敕，逐条限制场地与招式；玩家需在限制完全生效前击破敕令。
  • 正常路线 Boss：玉皇。
  • 正常玉皇分两个阶段：
  1. 法旨划分场地并召唤神将虚影。
  2. 玉皇亲自下场，用近距离权柄和瞬移压迫玩家。
  • 隐藏路线玉皇分三个阶段，主动移动，并与断轮印产生破坏权柄的交互。

3. 路线变化

状态：已锁定

  • 无雨乡固定为起点。
  • 罡风隘与天河录库可以交换顺序。
  • 玉京天阙固定为终点。
  • 区域内部从“普通战、精英、小神仙事件、商店、休整、失名旧我”中生成。

  • 每个区域有一个固定双阶段精英。

五、战斗系统

1. 核心定位

状态：已锁定

  • 正常敌人使用单条生命。
  • Boss 使用多阶段结构。
  • 战斗深度为中等：
  • 轻击。
  • 重击。
  • 挑空。
  • 空中追击。
  • 防御。
  • 闪避。
  • 精准格挡。
  • 3 个主动武功。

核心能力层级：

  1. 站位与距离决定局势。
  2. 精准格挡决定攻防转换。
  3. 武器切换负责解决具体距离、防御和敌人阶段问题。

手柄参考布局

  • A：跳跃

2. 双资源

状态：已锁定

气

  • 用于防御、闪避、移动技能和特殊移动。
  • 缓慢恢复。
  • 鼓励玩家管理生存资源。

势

  • 通过普攻命中、连段和精准格挡积攒。
  • 用于释放主动武功。
  • 受击会降低或打断势。
  • 势不会在没有战斗行为时自然刷满。

3. 防御与格挡

状态：已锁定

  • 长按防御。
  • 消耗气的闪避。
  • 精准格挡。
  • 防御拥有独立架势值。
  • 连续受击会破防，重击与部分武功更有效。

精准格挡成功：

  • 恢复气。
  • 积攒势。
  • 使敌人短暂硬直。
  • 不同武器可衔接自己的反击招式。

精准格挡失败：

  • 自动转为普通防御。
  • 额外消耗气。
  • 增加架势值。

4. 五种武器格挡原型

状态：已锁定

原型防御特征
短兵窗口最短，反击收益最高
长兵正面范围宽，收招较慢
重兵可承受多段，精准格挡造成更大硬直或破霸体
软兵窗口较宽，偏推开、转移方向和重整距离
远程特殊格挡近战精准格挡较弱，可偏转 projectile 或反击突进

基础武器清单：

  • 短兵：短剑、直剑、双匕。
  • 长兵：长枪、棍、戟。
  • 重兵：斧、锤、盾刃。
  • 软兵：鞭、链、流星锤。
  • 远程：弓、弩、暗器。

数量规则：

  • 武器不设固定总量。
  • 新增武器必须填充明确玩法缺口。
  • 新增武器必须拥有独立距离、节奏或格挡差异。

5. 双武器

状态：已锁定

  • 玩家携带 2 把武器。
  • 每把武器拥有独立连段计数。
  • 切换后可使用一次专用换武攻击。
  • 原武器连段中断。
  • 切换存在冷却。
  • 受击硬直中不能切换。
  • 普通战斗平均切换 1–3 次。

6. 武功秘籍

状态：已锁定

  • 秘籍完全独立，不设公开的刚柔快破险门派。
  • 每本秘籍围绕一个主要触发条件。
  • 每本秘籍提供一个主要效果。
  • 后台可用隐藏标签平衡，不在界面显示为门派。
  • 新增秘籍不设总量，但必须填补构筑缺口。
  • 主动招式最多 3 个。
  • 被动秘籍效果最多 4 个。
  • 主动招式通过“武功修饰键 + 攻击键”释放。
  • 主动招式消耗势。

7. 武器切换规则

状态：已锁定

  • 玩家同时携带 2 把武器。
  • 每把武器拥有独立连段计数。
  • 切换后可使用一次专用换武攻击。
  • 原武器连段中断。
  • 切换存在冷却。
  • 受击硬直中不能切换。

8. 防具与信物

防具

状态：已锁定

  • 1 个防具槽。
  • 每件防具拥有独立被动。
  • 防具不设固定总量，按玩法缺口补充。
  • 新增防具必须围绕明确机制，不能只增加数值。

信物

状态：已锁定

  • 无限携带。
  • 所有收集信物效果同时生效。
  • 可以混合条件触发、常驻效果和随机效果。
  • 同名信物不能重复叠加。
  • 信物不直接提供无限增长攻击、生命或势。
  • 资源生成类效果必须有每次战斗上限，不能形成循环。
  • 战斗界面只显示已触发或即将触发的信物。
  • 完整信物列表放在构筑页。

9. 物品升级与稀有度

状态：已锁定

  • 不设物品等级。
  • 不设普通、精良、神品等稀有度版本。
  • 武器、秘籍和防具没有多层升级。
  • 玩家通过替换、组合和休整节点调整构筑。
  • 休整节点可以强化或替换一个招式，不提供物品等级。

10. 武器与物品解锁

状态：已锁定

  • 曾经拾取一次，物品永久加入对应区域与后续区域奖励池。

  • 不读取当前按键。
  • 反击前有明显动作和音效。
  • 预测成功不会秒杀，只创造一次优势攻击窗口。

  • 出现概率受区域、路线和证词数量影响。

  • 未出现不会自动占据普通节点。
