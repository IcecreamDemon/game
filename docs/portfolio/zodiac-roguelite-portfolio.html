01 / PROJECT OVERVIEW
项目概览
02

主线围绕冷峻寡言的鼠光展开。十二生肖在同一次登天战中全部阵亡，阎王以一次性还魂契把鼠光送回天路；玩家在分支地图上选择路线，获得武器、武功秘籍、防具与信物，并即时改变本局战斗方式。

核心玩家幻想：用鼠光的武功与能力持续登天，在一次次死亡中识破阎王，并决定自己究竟为百姓、为同伴，还是为复仇而战。
60–120分钟 / 单局目标时长
20节点 / 完整登天局
3–5轮 / 正常主线目标
2结局 / 正常与断轮

四条设计支柱

01 / CHARACTER AS RULE

角色就是规则

鼠可进入地洞，龙可消耗气力飞行。生肖能力改变移动、站位和关卡路线，而不是只提供数值差异。

02 / BUILD IN RUN

构筑发生在局内

武器决定基础连招，秘籍拾取后即时生效，玩家必须根据路线与敌人临时调整招式组合。

03 / HOST MORAL COST

寄身产生道德代价

每轮都有一名清醒的承愿者被压制在体内。无论通关还是死亡，身体最终都会衰亡。

04 / READABLE DUELS

对决必须可读

高强度攻击拥有清楚预备动作；即使阎王复制玩家习惯，反击也必须可识别、可破解。

十二神相录 / 概念设计案 02
02 / WORLD & TRUTH
世界与真相
03

天庭统治三界，却将凡人视为维持秩序的成本。十二生肖不是天庭敕封的神将，而是代表农户、百姓与普通劳动者的民间抵抗者。他们从不同方向共同进攻天庭，最终全部阵亡。

PLAYER BELIEF

玩家最初知道的事

鼠光首次战死后，阎王以一次性还魂契把他送回。此后阎王声称使用的是已经死亡、自愿帮助英雄的身体，隐瞒承愿者仍然活着。

HIDDEN TRUTH

被掩盖的真相

第一次还魂使用鼠光自己的身体。后续每轮使用一名活着的承愿者，他们全程清醒，能感受疼痛却无法控制身体。无论胜负，身体最终都会死亡。

三层真相

一层 / 信任

阎王是唯一愿意帮助十二生肖的神，还魂契是共同反抗天庭的必要代价。

二层 / 活借

鼠光已经死了。后续每次回归都寄宿在活人身上，让对方清醒承受战斗，而鼠光对真相一无所知。

三层 / 取代

阎王从未想帮助民间。他利用十二生肖削弱天庭、收集战斗数据，准备取代玉皇。

公开称呼是“承愿者”，阎王台账中却写作“活借”，系统统一称“寄身者”。这套语言差异直接表现阎王如何把活人包装成可以消耗的工具。
玄简

掌籍郎。被阎王扣押生死簿页，暗中保存十二生肖的真名与残页。

兔昭

鼠光唯一愿意信任的朋友。乐观、相信未来，却在同一场登天战中牺牲。

阎王

表面是冥府管理者与秘密盟友，实际以还魂契为吸收通道，等待夺取天庭。

03 / NARRATIVE & ENDINGS
叙事结构与双终局
04

主线固定围绕鼠光。兔昭拥有一段不可替代的战斗短章，其他生肖通过旧我、小神仙事件与轮回试炼补充群像。所有剧情插入都发生在返回冥府或区域结算之后，不打断进行中的战斗。

序章共同登天，鼠光与兔昭先后战死
活体寄身阎王谎称使用的是死者身体
登天调查旧我逐渐像玩家，线索分散在路线中
击败玉皇双方互相算计，阎王将还魂契变成吸收通道
终局分岔正常路线或提前收集证词后的断轮路线
NORMAL ENDING

正常结局：轮回吞没

  • 玉皇揭露自己一直用鼠光作诱饵；阎王则早有预谋，等待夺取玉皇力量。
  • 玉皇被杀死，阎王顺着还魂契吸收其神魂与权柄。
  • 玄简牺牲自己的生死簿页，把鼠光从契约中拉出。
  • 最终战分三阶段：夺天、旧相、判录。
  • 鼠光与失控的轮回一同消失；天庭崩解，但伤亡无法挽回。
  • 多数被困承愿者随冥府崩坏失散，只有少数灵魂逃出。
  • 百姓只记得十二生肖的故事，最终形成《十二神相录》。
HIDDEN ENDING

断轮结局：主动宣战

  • 关键轮回证词集齐后，结算界面出现“断轮门”。
  • 提前击败未吸收玉皇的阎王，获得附着于所有武器的“断轮印”。
  • 断轮印可破除神力护盾、复活和锁定状态，不提供高额数值。
  • 以一条命完成 20 节点登天，区域 Boss 后仅恢复部分生命。
  • 未被使用的承愿者回到人间，所有被困灵魂获释；最终寄身者身体死亡但灵魂能够轮回。
  • 击败并封印玉皇，兔昭获释，玄简保住姓名。
断轮路线死亡后回到断轮门，保留证词但失去断轮印；击败缩短版阎王残念后可重新挑战。隐藏结局更困难，也让更多人活下来，但鼠光仍需留在冥府守望轮回。
线索

部分小神仙事件、兔昭残页与猴影档案共同构成轮回见闻。

终局主题

阎王能复制招式与习惯，却无法复制鼠光改变自己的选择。

角色弧光

鼠光从冷峻复仇，走向承担活借带来的责任。

04 / CORE LOOP
核心循环
05

单局循环同时连接战斗、构筑、路线和轮回线索。玩家不断在“立即变强”与“追查真相”之间做选择。

核心循环：鼠光归返 → 路线决策 → 对决 → 即时构筑 → 结算 → 可选证词追查。
战斗决策

正面交换、拉开距离，还是切换武器创造克制？

构筑决策

新秘籍是否值得占用招式槽，应该替换谁？

路线决策

追逐成果、寻找商店，还是追查可能出现的失名旧我？

05 / RUN STRUCTURE
地图与单局节奏
06

一局固定经过 20 个节点，分为无雨乡、罡风隘、天河录库与玉京天阙四个区域，每区 5 个节点。罡风隘与天河录库可交换顺序。

路线应提供明确风险差异。失名旧我不会必然出现，但玩家可通过特定路线提高追查概率。
节点类型 主要作用 玩家决策
普通对决进行单血条 1v1 战斗是否冒险换取成长
精英 / 旧我高强度敌人或可选证词追查构筑是否足以应对额外风险
奇遇事件提供风险交换或规则变化是否牺牲当前资源换取未来能力
商店购买武器、秘籍或恢复资源是否为当前流派投入资源
Boss多阶段高强度战斗，阶段数按敌人配置是否已经具备稳定应对手段
十二神相录 / 概念设计案 06
06 / CHARACTER SYSTEM
生肖角色系统
07

主线固定使用鼠光。其他生肖共用同一套动作框架，在轮回试炼中作为额外角色开放。差异集中在数值、特殊能力与招式改写，既能保证敌人和关卡可复用，也能真正改变解法。

REPRESENTATIVE / RAT

鼠：高速近身与绕后

特殊能力：打洞

  • 只能进入预先标记的软土、墙脚或地洞。
  • 消耗专用资源，不能无限停留在地下。
  • 出口可识别，敌人能够预判或封锁。

关卡影响：把侧向地洞变成绕过正面防线的高风险路线。

REPRESENTATIVE / DRAGON

龙：空中压制与机动

特殊能力：飞行

  • 持续飞行消耗气力，耗尽后只能滑翔。
  • 竞技场可通过天花板、飞镖与强风限制空域。
  • 空中仍需承受清晰的反空攻击威胁。

关卡影响：取得高度优势，但必须管理气力与落点。

角色差异维度

机动

移动速度、跳跃高度、冲刺距离与空中控制。

交战

攻击距离、连招节奏、硬直能力与防御效率。

规则

特殊资源、核心技能，以及由此产生的专属关卡路线。

平衡原则：数值差异决定角色倾向，特殊能力决定解关方式。强力移动能力必须附带资源、空间或时间成本。
十二神相录 / 概念设计案 07
07 / COMBAT & BUILD
战斗与构筑系统
08

战斗以横版竞技场中的攻防交换为核心。普通敌人使用单条生命；Boss 使用多阶段结构，逐层测试玩家对操作、站位与构筑的理解。

观察辨认武器、站位和起手动作
试探确认攻击距离与防守习惯
交换使用连招、防御、闪避与技能
调整切换武器或启用新获得的秘籍
结算选择奖励并返回地图路线
WEAPON

武器：决定基础连招

  • 玩家同时携带 2 把武器。
  • 每把武器拥有独立连段与攻击距离。
  • 切换存在冷却，受击硬直中不能切换。
  • 武器形成快攻、破防、牵制等节奏差异。
MANUAL

秘籍：即刻改写招式

  • 拾取后立即生效，无需回到局外配置。
  • 最多保留 3 个主动招式。
  • 满槽时选择替换已有招式或放弃新招式。
  • 部分秘籍修改普攻、跳跃攻击或武器切换。

四类物品的职责

类别作用是否跨局保留
武器决定普攻、连招、攻击距离和节奏不保留，只解锁可出现的种类
武功秘籍提供主动招式或改写连招不保留，只解锁可出现的种类
防具改变防御、硬直和生存规则不保留
信物提供特殊规则和组合条件不保留
构筑目标不是叠加最高伤害，而是形成能同时处理不同距离、不同敌人节奏和不同场地问题的组合。
十二神相录 / 概念设计案 08
08 / HOST & OLD SELF
活体寄身与失名旧我
09

第一次回归使用鼠光自己的身体。后续每轮由一名活着的承愿者提供身体。他们意识清醒却无法控制，阎王则对鼠光谎称那只是已经死亡的自愿身体。

识别

旧我用鼠光的动作暴露模仿痕迹，但身体和被困意识属于承愿者。

风险

失名旧我进入可选精英池，概率受区域、路线和证词数量影响。

公平

旧我只学习三种行为习惯，不继承无预警秒杀能力。

“旧我”是清醒承愿者、被压抑的意识与鼠光战斗记录共同形成的困魂实体。击败它是释放宿主并获得隐藏结局证词的机会，不是普通流程必须完成的固定任务。

09 / LEVEL DESIGN FRAMEWORK
关卡设计方法
10

关卡不是从入口跑到出口，而是让同一套 1v1 规则在不同空间条件下产生变化。设计的核心问题是：地形怎样改变玩家的站位、距离与能力价值？

交战空间

距离

主战区保持开阔，避免平台过多切断近战交锋，同时让远程与突进产生明确强弱位置。

垂直空间

高度

平台给予压制角度，也增加落地与追击成本。飞行能力不能无条件取消这项代价。

角色路线

差异

地洞与空域提供专属解法，但必须有固定出口、反空攻击或资源成本来维持对抗。

系统如何落到关卡

系统具体关卡表达
生肖数值速度、跳跃与攻击距离改变安全区、追击路线和平台价值。
特殊技能鼠的地洞与龙的飞行生成专属路线，并引入预判、气力和反空约束。
武器切换不同高度与敌人阶段需要不同攻击距离和连招节奏。
武功秘籍特定组合可以缩短战斗，但要求玩家在路线中完成构筑。
失名旧我可选精英沿用原场地规则，并作为宿主释放与隐藏证词来源。
环境机关机关对双方生效，周期改变站位、恢复窗口和进攻时机。
关卡验收标准：角色能力必须带来不同解法，但不能让玩家绕过对决本身；玩家失败后应能说出下一次需要改变的行为。

10 / LEVEL CASE
普通关卡案例：悬索擂台
11

悬索擂台用于教学“角色能力与路线选择”的关系。它是一屏横版竞技场，敌人使用单条生命，重点是距离管理和专属路线取舍。

鼠
敌
鼠类地洞：出口固定且可预判
龙类空域：反空与气力限制
悬索擂台：地面负责 1v1 正面交锋，上层平台改变压制角度，专属路线提供高收益入口。
战斗过程
  1. 地面开局，双方确认攻击距离与防御方式。
  2. 敌人水平突进，迫使玩家改变站位或跳上平台。
  3. 鼠可钻洞绕后，但出口会被预判或封锁。
  4. 龙可取得空中优势，但需管理气力与落地位置。
  5. 胜利后奖励位于风险侧，玩家决定是否立即拾取。
验证问题
  • 鼠和龙是否都能利用场地，却不能跳过整场战斗？
  • 其他角色是否仍能用基础平台和武器切换处理同类问题？
  • 敌人是否能对不同高度和绕后路线做出可理解回应？
十二神相录 / 概念设计案 11
11 / BOSS CASE
Boss 案例：削名判官
12

削名判官驻守天河录库，负责抹除失踪者、承愿者与反抗者的姓名。他测试玩家能否在部分构筑被封锁时调整打法。

PHASE 01 / 录名

观察构筑

判官记录玩家常用的武器与武功，并在卷宗中写下能力名称。

玩家任务：交替使用不同武器和招式，避免单一构筑被完全锁定。

失败特征：只依赖同一套连招与武器。

PHASE 02 / 削名

临时封锁

最多封锁一个武器槽或一个主动招式，场地出现对应封条。

玩家任务：判断继续进攻还是优先破除封锁，恢复完整构筑。

失败特征：忽略封条，继续依赖已被封锁的能力。

PHASE 03 / 判词

规则成真

判官写下最多两条场地规则，例如禁止跳跃、封锁武器或周期落判。

玩家任务：击破对应封条推翻判词，同时保持站位与资源。

失败特征：同时处理两条规则时失去节奏。

判词规则

最多同时生效两条，第三条替换最早一条。每条判词都有明确文字、场地标记和至少一种破除方式，不能封锁唯一生存手段。

失败反馈

玩家应能指出自己忽略的封条或过度依赖的招式，而不是感觉能力被随机禁用。

Boss 设计目标：把“名字被抹除”转化为可读的构筑限制，并通过击破封条让玩家夺回主动权。
十二神相录 / 概念设计案 12
12 / DESIGN TRADE-OFFS
关键取舍与风险控制
13

作品集不只展示“想做什么”，还要说明“为什么这样做”和“如何避免范围失控”。以下取舍用于保证系统、关卡与制作复杂度保持可控。

WHY BRANCHING MAP

为什么采用分支地图

让玩家在战斗前做风险选择，并连接战斗、奖励和隐藏证词追查，而不只是改变关卡顺序。

WHY MANUALS ARE INSTANT

为什么秘籍即时生效

强化临场调整和路线价值。每次拾取都可能改变后续决策，而不是局外固定配装。

WHY NO PERMANENT STATS

为什么不保留永久成长

避免死亡循环变成刷属性，让玩家成长主要来自知识、操作与组合理解。

WHY BURROW COSTS QI

为什么潜地持续消耗气

主地面可自由潜地，但地下移动持续消耗气，并留下暴露位置的地面裂纹；敌人可用踏地、地刺和范围攻击反制。

风险控制方式
十二生肖内容过大共用动作框架；差异集中在数值、一个特殊能力和少量招式改写；关卡只增加角色专属路线。
飞行破坏关卡气力限制、反空攻击、空域约束，并让地面路线拥有不同收益。
格斗式 AI 复杂敌人使用少量行为模块；“旧我”复用已有模块，不模拟完整玩家操作。
活借的道德压力前期保持暧昧；旧我设为可选；每次释放宿主都有明确反馈；隐藏结局统一解救未死者。
构筑难以理解围绕少量明确标签建立效果；界面只显示关键状态与主动招式。
范围控制原则：先完成系统之间的闭环，再增加角色和内容。十二生肖的差异必须能落回同一套战斗与关卡语法。

15 / COMBAT PROTOTYPE
战斗原型规格
16

战斗原型围绕四资源、可读受击状态和两段共用起手后的连招分支展开。所有帧数和消耗先进入 Combat Lab 实测，不直接写死为最终数值。

DEFENSE RESOURCE

气负责生存

防御、闪避和潜地消耗气；精准格挡恢复气并制造反击机会。受击时气达到阈值，可手动发动一次绝境精准格挡。

OFFENSE RESOURCE

势负责进攻

所有攻击消耗势，命中与精准格挡继续积累势；非攻击状态每秒缓慢恢复 2 点，攻击期间暂停，形成持续攻防压力。

受击状态

状态来源后续处理
僵直普通攻击、平推攻击短暂无法行动，硬直结束后恢复
击飞上挑或击飞类招式支持有限追击，落地后进入倒地
倒地砸地击、击飞落地可接地面重击，随后直接起身
COMBO GRAMMAR

轻1 → 轻2 后，可按轻击、前+轻击、上+轻击、重击或换武分支。

AIR COMBO

空中轻击沿用地面逻辑；空中重击为砸地击，落地后使目标倒地。

JUGGLE BUDGET

普通敌人 3 次、精英 2 次、Boss 1 次浮空追击；重型敌人可以不可击飞。

鼠光特殊能力：主地面可自由潜地，地下持续耗气并暴露近似位置。钻出没有惩罚性硬直，按攻击可立即衔接破土上挑。
